## Sobre mim

Trabalho na interseção entre **segurança da informação** e **automação**, com foco em governança de acessos, Segregação de Funções (SoD) e Sensitive Access Transactions (SAT).

Construo ferramentas locais, determinísticas e auditáveis que ajudam organizações a identificar conflitos de acesso, conciliar bases e produzir resultados rastreáveis — sem depender de soluções genéricas de mercado.

```text
Domínio principal   → IAM · SoD · SAT · Governança de Acessos
Abordagem           → Local-first · Determinístico · Auditável
Linguagem principal → Python 3.12+
```

## Projetos em destaque

### 🔐 [IAM Brasil | Governança SoD & SAT](https://github.com/TalesGiovanini/iam-brasil-governanca-sod-sat)

> Plataforma local de análise de Segregação de Funções e Sensitive Access Transactions.

- Identifica conflitos de acesso entre perfis e funcionalidades em planilhas heterogêneas
- Concilia bases nos dois sentidos e bloqueia resultados quando há divergências críticas
- Gera Matriz Funcional, Atividades Conflitantes e SAT no template Excel definido pelo cliente
- Interface gráfica desktop (Tkinter) e execução por linha de comando
- **100% local** — dados de clientes nunca saem da máquina

```
Python · Pandas · OpenPyXL · Tkinter · SQLite
```

---

### 🤖 [Tales Agent Platform](https://github.com/TalesGiovanini/iam-brasil-governanca-sod-sat)

> Plataforma de automação local-first, CLI-first e independente de provedores externos.

- Core determinístico com Policy Engine para controle de acesso a diretórios
- Módulo de inferência plugável e opcionalmente desabilitado — o sistema funciona sem ele
- CLI extensível com arquitetura em camadas (Core / Agent / Tools / Knowledge / Memory)
- Workflows determinísticos executáveis sem qualquer provedor externo

```
Python · SQLite · YAML · argparse
```

## Princípios que guiam meu trabalho

```text
✔  Local-first         → dados sob controle do usuário, não na nuvem
✔  Determinístico      → o mesmo input produz sempre o mesmo output
✔  Auditável           → toda ação relevante tem log, origem e resultado
✔  Menor privilégio    → acesso apenas ao que é estritamente necessário
✔  Sem dependência     → nenhuma regra de negócio depende de provedor externo
```
